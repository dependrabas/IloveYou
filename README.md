# I Love You — animated page

Open `index.html` in your browser to see a small animated "I love you" card. It uses only HTML, CSS, and JavaScript — no build step.

Tips:

- Double-click `index.html` or open it via your browser's File > Open.
- For development, serve the folder with a simple HTTP server if you prefer:

  python3 -m http.server 8000

Then visit http://localhost:8000 in your browser.
